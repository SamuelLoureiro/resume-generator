# Descrição da vaga

A OmniData Solutions constrói infraestrutura moderna de dados e analytics para empresas globais.
Estamos em busca de um(a) Estagiário(a) em Engenharia de Dados motivado para compor nossa equipe de Data Platform.

## Responsabilidades
- Desenvolver scripts em Python para ingestão de dados, web scraping e pipelines ETL de fontes públicas e privadas.
- Criar tabelas, índices e views otimizadas em PostgreSQL para sustentar cargas de trabalho analíticas.
- Monitorar a integridade, consistência e qualidade dos dados ao longo das etapas de transformação.
- Automatizar rotinas de carga de dados utilizando Docker e agendadores de tarefas.

## Requisitos obrigatórios
- Cursando graduação na área de Tecnologia da Informação ou Engenharia.
- Boa habilidade em Python para automação e manipulação de arquivos estruturados (JSON, CSV, Parquet).
- Domínio da linguagem SQL (DML, DDL, joins complexos, window functions).
- Noções de bancos de dados relacionais e modelagem tabular.

## Desejáveis
- Experiência em projetos de web scraping ou ingestão de APIs.
- Conhecimento prático de Docker e comandos essenciais de terminal Linux.
