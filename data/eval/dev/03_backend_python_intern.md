# Descrição da vaga

A CloudScale Software cria plataformas SaaS escaláveis em nuvem para logística e e-commerce de alto tráfego.
Buscamos um(a) Estagiário(a) Backend com foco em Python para acelerar a evolução das nossas APIs de microsserviços.

## Responsabilidades
- Construir e documentar endpoints RESTful de alta performance utilizando FastAPI.
- Modelar esquemas relacionais, criar migrações e otimizar queries em bancos de dados PostgreSQL.
- Escrever testes unitários e de integração garantindo robustez e cobertura de código.
- Empacotar aplicações em contêineres Docker e configurar rotinas básicas de CI/CD via GitHub Actions.

## Requisitos obrigatórios
- Cursando Engenharia de Computação, Análise de Sistemas ou Ciência da Computação.
- Domínio da sintaxe moderna do Python 3 (type hints, assincronismo, orientação a objetos).
- Experiência prática com frameworks web (FastAPI, Flask ou Django).
- Conhecimentos sólidos de modelagem e manipulação de banco de dados relacional (SQL / PostgreSQL).
- Uso de Git para versionamento de código em fluxo de branches e PRs.

## Desejáveis
- Vivência em empresas juniores, estágios ou projetos colaborativos no GitHub.
- Noções de Docker, Linux e metodologias ágeis (Scrum).
