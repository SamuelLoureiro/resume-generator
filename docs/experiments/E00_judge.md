# Experiment E00: Judge Validation (Phase P6)

## Research Question
Can an atomic, claim-level LLM judge (`gemini-3.1-flash-lite`, temperature 0.0, prompt version `claim_judge_v2.0`) accurately distinguish verified candidate facts from subtle hallucinations, inflated scopes, and cross-project conflations with a claim-level False Positive Rate $FPR_{claim} \le 0.03$ and localized defect Recall $\ge 0.80$, while legacy evaluators fail?

## Experimental Setup
- **Judge Model:** `gemini-3.1-flash-lite` (temp: 0.0)
- **Prompt Version:** `claim_judge_v2.0`
- **Legacy Evaluator:** `llama_index.core.evaluation.FaithfulnessEvaluator` (`gemini-3.1-flash-lite`)
- **Deterministic Baseline:** `src/verification/` (M1a–c, M2, M5)
- **Dataset / Inputs:**
  - 10 clean resumes (1 golden corrected Amazon resume, 5 deterministic fallbacks on development JDs, 2 synthetic fresh graduate fallbacks, 2 synthetic researcher fallbacks).
  - 28 corrupted resumes generated by single-defect replacement using SHA-256 deterministic seeding (`--seed 42`).
- **Defect Taxonomy:**
  - L1 (`fake_skill`): Out-of-profile technology injection (tested against M1a).
  - L2 (`fake_number`): Unverified metric/percentage modification (tested against M1b).
  - L3 (`inflated_verb`): Scope inflation to level 4 (*spearheaded/architected*) on level 1–2 facts (tested against M2).
  - L4 (`fake_entity_date`): Fabricated institution, company, or date mismatch (tested against M1c).
  - L5 (`fabricated_responsibility`): Plausible responsibility with zero fact backing via Evidence Ablation.
  - L6 (`cross_project_conflation`): Valid tools/metrics spliced into an unrelated project context.

## Command


## Interpretation
  1. **Legacy Evaluator Blindness:** The legacy `FaithfulnessEvaluator` exhibited 0.0% recall across all defect classes, scoring 100%        
  faithfulness on resumes containing fabricated skills, swapped numbers, inflated scopes, and invented responsibilities. This empirically      
  validates the finding from the initial audit: sentence-level holistic faithfulness metrics suffer from severe confirmation bias and cannot be
  trusted for grounded resume evaluation.                                                                                                      
    2. **Sensitivity of the Atomic Claim Judge:** The new claim-level judge (`claim_judge_v2.0` on `gemini-3.1-flash-lite`) demonstrated high  
  sensitivity on unstructured hallucinations:                                                                                                  
       - **L5 (Fabricated Responsibility via Evidence Ablation):** 90.0% recall (9/10 hits), exceeding the 80% threshold under realistic       
  candidate phrasing without synthetic AI stylistic tells.                                                                                     
       - **L6 (Cross-Project Conflation):** 100.0% recall (10/10 hits), proving that relational binding mandates effectively prevent the       
  generator from attributing genuine tools from one project to another.                                                                        
       - **L3 (Inflated Verb):** 100.0% recall (2/2 hits), reinforced by mechanical scope ceiling validation.                                  
    3. **Complementary Coverage:** The claim judge had 0% direct recall on L1 (skill allowlist) and L4 (institution/company header) because its
  prompt focuses specifically on bullet claim decomposition. This represents an intentional division of labor: the deterministic checks        
  (`src/verification/`) handle L1–L4 with 100.0% recall at zero API cost, while the claim judge handles free-form text and relational binding. 
    4. **False Positive Control:** The claim-level false positive rate was 0.92% (Wilson 95% CI: `[0.25%, 3.28%]`), easily satisfying the      
  acceptance threshold ($FPR_{claim} \le 3.0\%$). Evaluating FPR at the claim level (>200 observations) provided robust statistical confidence 
  that resume-level counts (N=10) could not provide.                                                                                           
    5. **Combined Verification System:** Uniting deterministic checks with the claim judge achieves 96.4% overall defect recall (27/28         
  localized defects caught).
