# Core Software Engineering, Systems, and Algorithms Internships

## 1. What Tech Recruiters Look for in Core SWE and Systems Interns
Core Software Engineering and Systems roles (at companies building mission-critical engines, infrastructure, compilers, or high-performance platforms) focus heavily on foundational computer science competence:
- **Algorithmic Mastery & Data Structures:** Fluency with arrays, linked lists, hash maps, trees (binary, BST, trie), graphs, heaps, and classic algorithmic techniques (sorting, searching, dynamic programming, divide-and-conquer).
- **Complexity Analysis (Big-O):** Ability to analyze and optimize time complexity and space/memory overhead of implementations.
- **Compiled and Systems Languages:** Proficiency in `C` and `C++`, understanding memory allocation, pointers, references, and compiled executable lifecycles, alongside modern scripting in `Python`.
- **Unix/Linux Operating Systems:** Comfort working directly in Linux terminal environments, understanding file systems, process management, shell scripting, and debugging tools.
- **Engineering Discipline:** Automated unit testing, clean code principles, version control with Git branching, and systematic debugging under pressure.

---

## 2. Positioning Academic Rigor and Extracurricular Differentiators
For students applying to core engineering programs, traditional industrial experience is often secondary to verified technical competence:

### 1. Competitive Programming and Hackathons
- Highlight participation and regional/national classifications in official contests like the **Maratona SBC de Programação**, ICPC, or OBI.
- Emphasize speed of implementation, edge-case handling, and algorithmic problem-solving under strict time limits.
- Example bullet: *"Competed in the Maratona SBC de Programação (2023 & 2024), solving complex algorithmic challenges under strict time and memory constraints."*

### 2. Teaching Assistantships (Monitoria) and Academic Excellence
- Serving as a Teaching Assistant (Monitor) in foundational courses (e.g., *Introduction to Computer Science*, *Algorithms*) proves mastery of fundamentals and peer mentorship.
- High academic metrics (GPA / Coeficiente de Rendimento) and bilingual technical communication (e.g., *Advanced / C1 English*) indicate rapid learning agility and readiness for international engineering teams.

### 3. Systems and Algorithmic Project Framing
- Highlight modular architecture, algorithmic trade-offs, and profiling/benchmarking.
- Mention code quality standards: rigorous test suites (`pytest`, unit test frameworks), Git flow, and adherence to clean design patterns.

### 4. Technical Skills Prioritization for Core SWE
- **Languages:** C, C++, Python, Bash / Shell Scripting.
- **Foundations:** Estruturas de Dados (Árvores, Grafos, Hash Tables, Heaps), Algoritmos, Análise de Complexidade (Big-O).
- **Systems & Tools:** Linux, Git/GitHub, Docker, Make / Build Systems, Compilers, Debugging.
- **Practices:** Test-Driven Development, Modular Architecture, Code Review, Performance Profiling.

## 3. High-Value Action Verbs and ATS Keywords for Core SWE
- **Action Verbs:** *Architected, Implemented, Optimized, Benchmarked, Debugged, Refactored, Profiled, Solved, Formulated, Automated, Tested, Integrated.*
- **ATS Keywords:** `Software Engineering`, `Data Structures`, `Algorithms`, `Big-O Notation`, `C/C++`, `Python`, `Linux`, `Competitive Programming`, `Maratona SBC`, `Memory Management`, `Unit Testing`, `Systems Programming`, `Git`.
